How a component gets built

Every component moves through the same five stages before it ships — requirements become behaviour, behaviour becomes tests, and the tests drive the implementation.

  1. 01

    Requirements

    What the component has to do, written down first.

    Spec doc · Design doc · Image
  2. 02

    Behaviour spec

    The requirement turned into concrete, testable BDD scenarios.

  3. 03

    Tests written

    Written against the spec and failing on purpose — the red phase.

  4. 04

    Implementation

    Code written until every one of those tests turns green.

  5. 05

    Tested component

    A working, verified component, ready to ship.
